# Referência de engenharia fixa

`manual_engenharia.xlsx` é uma cópia integral do arquivo
`Mnaual de Engenharia Blossom.xlsx` fornecido pelo usuário como referência fixa.
Não foi recalculado, modificado ou convertido.

SHA-256: `cbd1da49a5afb5f33baac8b32cb377f38ffaf6ff2d3deab5db4181515d1671ac`.

O site verifica essa identificação antes de gerar, e o Excel registra o hash
na aba Parametros. A revisão deve ser alterada por atualização explícita do
arquivo e de `blossom/fixed_manual.py`, com revisão das observações do manual.
Ela não é escolhida pelo visitante nem enviada junto com a LD.

O manual acompanha a distribuição do código para funcionar tanto na hospedagem
atual quanto no Docker. Isso não completa a interpretação das regras técnicas:
as evidências e observações preliminares continuam sinalizadas para revisão.
